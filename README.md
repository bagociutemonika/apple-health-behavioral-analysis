# What can behavioral data tell us about activity patterns?

## Research question

What behavioral patterns can be identified in longitudinal activity data, and how could these patterns inform more personalized user experiences?

## About the project

This project explores longitudinal physical-activity data from an Apple Health export.

I use behavioral data to examine how activity varies across days, times, and over longer periods, and then translate the observed patterns into hypotheses for future user research.

The raw Apple Health data are not included because they contain personal information.

## What I investigated

- How does activity vary across weekdays and weekends?
- At what times of day does activity tend to occur?
- How consistent is activity over time?
- Are there recurring periods of lower activity?

## Key findings

The analysis covers **1,380 days** of recorded activity.

Average daily activity was approximately **7,089 steps**, with substantial variation between days.

Activity was somewhat higher on weekdays than weekends:

- Weekdays: **7,273 average steps**
- Weekends: **6,628 average steps**

Activity also varied across the day, with recorded step volume particularly concentrated in the afternoon and early evening.

Because hourly totals are influenced by the number of records captured at each hour, these patterns are interpreted as patterns in recorded activity rather than definitive evidence about the individual's most active hours.

## From behavioral data to user research

The observed patterns can be used to generate hypotheses for future research.

For example:

- Could activity feedback be more useful when it is adapted to a user's routine?
- Do users prefer goals that reflect differences between weekdays and weekends?
- Does showing longitudinal behavioral patterns help users understand their own activity?
